# 摸鱼保卫战 🐟

微信小游戏 · 合成 + 塔防 + 肉鸽三选一 · 纯广告变现（无内购；首发暂不展示广告入口，代码已预留）

> 上班是不可能认真上班的。合成装备，抵御老板，守住你的摸鱼时间。

## 玩法

- 你扮演打工人，守住工位：敌人（Bug、群消息、紧急需求、产品需求、会议邀请…）从屏幕上方压向工位
- 底部 4×4 棋盘即防线：**拖动两个相同装备合成升级**（LV1→LV5），装备自动攻击
- 击杀得经验 → 升级弹 **三选一技能**（白/蓝/紫/橙 四档品质，共 22 个；其中「手气不错/冷处理/摸鱼回血」是改打法的机制技能）
- **技能跨关继承**（`config.CARRY_SKILLS`，默认开）：打赢进入下一关会带走已选技能与词缀，输了重开清空——肉鸽 build 的寿命从单场 3~5 分钟延到整局，"选什么"开始影响"能打多深"。⚠️ 当前配平未完成（第 8 关通过率被抬到 100%），详见 `指标报告.md` 第二十节
- **摸鱼值 / 深度摸鱼**：击杀 +1.1、合成 +4 积累摸鱼值，攒满 100 点后点战斗 HUD 上的 **🐟** 进入 8 秒「深度摸鱼」：全体攻速 ×2、金币收益 ×2。这是全游戏唯一一个可以主动按的技能键
- **关卡剧情**：每关**第一次**进入时放一张很轻的剧情卡（点一下过）；第 1~8 关 2~3 行、第 9 关收尾卡 4 行接无尽，第 10 关起不再出现；三个 Boss 各有一句登场台词（战场提示条）
- **首发不展示任何广告入口**（`config.ADS_ENABLED=false`）：服务层/失败重试/看门狗/4 个 placement/埋点全部保留，但复活/双倍/刷新/看广告宝箱四个入口都不出现；与广告绑定的每日任务与成就同步下线（任务池 9→8、成就 8→7）。开通流量主后填 `AD_UNIT_ID` + `ADS_ENABLED=true` + 重新提审即恢复
- 结算面板会复盘本局数据（合成/升级/最强装备）并预告下一关（Boss 关提前点名）
- 每 4 关一个 Boss 并按 产品经理 → 直属领导 → 大老板 轮换（分别会疯狂加需求、催进度全场加速、皮厚抗打）；8 关后进入无尽模式
- 每隔一段时间投放新装备补给；金币用于局外「工位升级」（显示器/人体工学椅/摸鱼学）
- **升星券**：打死 Boss 得 1 张，点 HUD 上的 ⬆️ 进入选择状态、再点棋盘上任意装备直接升一级（与"拖动合成"互补：合成要凑一对，升星券想升谁升谁）
- **敌人主攻列**：七成波次会集中在某一列压进来并打出红色预警带，把键盘挪到那一列能穿一整列（站位的意义）
- 战斗右上角 **×1/×2/×3 倍速快进**（子步进模拟防穿模，倍速偏好自动存档，新手教学阶段隐藏）
- **成就 7 项 + 图鉴/击杀统计**（首发广告关闭档；开通广告后 8 项）：首页左上角 📖 入口，两页签（成就进度条与领取 / 每种敌人被击退多少只 + 长期统计）
- **每日任务 3 个 + 每日免费宝箱**（不看广告）：首页左上角 📋 入口，任务覆盖"通关一局 / 合成 10 次 / 击杀 60 个"，跨天自动重置；这是"明天再来"的最短回路
- **摸鱼分**（击杀×8 + 关卡×800 + 剩余血量×25，公式在 `config.js calcScore`；权重调过一轮，现在"守得好"和"推得远"分量相当）与**好友摸鱼榜**（开放数据域读好友托管数据，免服务器；**分总榜与本周榜两个页签**，周榜每周一重置；结算自动上报总分与本周分，首页 🏆 查看，开发者工具内显示本地兜底视图）

**新手引导**（计划书 §16 落地）：**首次进入首页自动弹出 3 页图文玩法说明**（含合成/战场示意图、翻页圆点，`helpSeen` 存档后不再打扰，右上角 ❓ 可随时重看）；第 1 关开局冻结刷怪，高亮两个咖啡 + 手指沿虚线轨迹演示拖拽，玩家完成第一次合成后敌人慢 3 秒才进场；首次三选一有提示条。三步引导各自独立存档（`helpSeen` / `tutorialDone` / `skillTipDone`），老玩家不会被重复打扰。

## 运行

1. 用微信开发者工具「导入项目」选择本目录（appid 已配置）
2. 直接编译即可玩。首发 `ADS_ENABLED=false` 界面没有广告入口；开发时要走广告路径，把 `ADS_ENABLED` 临时改 `true`（`AD_UNIT_ID` 为空则走 3 秒「模拟广告」倒计时、奖励照发）

### 无头冒烟测试（Node，不需要开发者工具）

```bash
node test/smoke.js
# 期望输出：393 通过 / 0 失败（固定随机种子，结果可复现）

node test/harness.spec.js
# 桩忠实度自检：54 通过 / 0 失败（只测 test/harness.js，不加载游戏，<1s）
```

覆盖：进关 → 合成 → 刷怪击杀 → 三选一 → 暂停 → 胜利 → 双倍奖励（模拟广告）→ 下一关 → 失败 → 复活弹层 → 结算 → 工位升级 → 存档持久化/老存档迁移与字段兜底 → 词缀生效（减伤/护盾）→ 技能刷新扣次数时机 → 链式引爆单帧结算 → 技能全满级兜底 → 单帧异常兜底 → 广告监听器不泄漏 → 模拟广告吞输入 → 摸鱼值爆发 → 补给聚焦 → 单关三选一上限 → 技能跨关继承 → 难度曲线/经济 → 广告关闭档（四个入口全部不出现，但仍能正常走完一局）→ 剧情（只弹一次、可跳过、不断片）。

### 对局模拟器（无头，跑真实游戏代码）

```bash
node tools/sim.js                                  # 默认：普通机器人 3 玩家 × 8 session
node tools/sim.js --players 30 --sessions 3 --tier novice   # 新手档基线
node tools/sim.js --players 1 --sessions 1 --trace          # 逐帧追踪单 session
```

会输出节奏/行为/结果/挫败/经济/广告/压力七类指标，并按目标清单打勾，同时落盘 `tools/sim-<label>.json`。
机器人只走触摸入口操作（与真人同一路径），三档水平（新手/普通/熟练），固定种子可复现。
每轮改动的前后对比记在 `指标报告.md`。

## 配置广告位（首发关闭；开通流量主后启用）

首发先不开（`ADS_ENABLED = false`，默认）。4 处广告**代码与服务层全部保留**，只是界面不出现入口——首发拿不到流量主（要游戏圈有效活跃 / 累计 UV>500），留入口只会走 3 秒模拟广告再白送奖励，既污染经济又像假广告。

`js/core/config.js`：

```js
const AD_UNIT_ID = '';    // 填入微信后台创建的激励视频广告位 ID
const ADS_ENABLED = false; // 首发 false：界面不显示广告入口；填好 ID 后改 true 并重新提审
```

开通后生效的激励视频广告位共 4 处（`AD_UNIT_ID` + `ADS_ENABLED=true`）：

| 场景 | placement | 频控 | 按钮上的收益告知 |
|---|---|---|---|
| 死亡复活（回 50% 血 + 击退敌人） | `revive` | 每局 1 次 | 「看广告 复活（回 50% 血）」 |
| 结算金币翻倍 | `double` | 每次结算 1 次 | 「本局金币 ×2（+N 🪙）」带具体数额 |
| 三选一技能刷新 | `reroll` | 每局 2 次 | 「看广告换一批技能（剩 N 次）」 |
| 首页每日宝箱 | `chest` | 每天 3 次 | 「开宝箱 +80~220 🪙（今日剩 N 次）」带范围 |

**加载失败策略**：只有 `ADS_ENABLED=true` 且 `AD_UNIT_ID` 为空（开发/未配置）才走 3 秒模拟广告并照发奖励；线上加载失败会重试 2 次，仍失败则提示"广告暂时不可用，稍后再试"并**不发奖励**（绝不降级成白送），同时上报 `ad_unavailable`。

## 调参指南

所有数值集中在 `js/core/config.js`（数据驱动，改完即生效）：

- `WEAPONS`：4 种武器各级伤害/间隔/范围
- `ENEMIES`：敌人血量/速度/啃工位伤害/经验/金币
- `buildLevel(n)` / `BOSS_HP_MUL_BY_INDEX`：关卡时长、血量倍率（每关步进 0.26、8 关后指数 1.24）、Boss 倍率 `[1.2, 2.0, 1.25]`、刷怪节奏（改难度曲线只动这里）
- `SKILLS` / `RARITY_WEIGHT`：技能效果与白蓝紫橙权重（55/30/12/3）
- `UPGRADES` / `UPGRADE_COST`：局外成长数值（基数 180，三条战斗线总价 4377→13131；当前代码实测三线满级约 26.5 单场，纯登录奖励要 15 天左右）
- `expNeed`：经验曲线（`9 + 9×(等级-1)`；现在它只管"这一关的三选一什么时候来"，不管一关能拿几次）
- `MAX_PICKS_PER_BATTLE`：单关三选一上限（3 次）。它切断"build 越强→打得越深→经验越多→拿得越多"的正反馈；经验仍照常消耗，只是不再兑现成选择
- `CARRY_SKILLS`：技能是否跨关继承（默认 `true`）。**配平尚未完成**，关掉即退回旧的"单场 build"手感，见 `指标报告.md` 第二十节
- `SLACK_*` / `SLACK_BTN`：摸鱼值积累（击杀 +1.1 / 合成 +4）、爆发时长 8 秒、攻速与金币倍率、HUD 按钮位置
- `SUPPLY_FOCUS_CHANCE` / `pickSupplyType`：补给有 62% 概率跟随棋盘上正在堆的那条线（LV5 可达性的关键）
- `SHIELD_PER_STACK` / `ANNUAL_LEAVE_HP`：一次性护盾量（「明天再说」50/层）与「带薪年假」的生命上限加成（80/层；跨关重建时补回）
- `ADS_ENABLED`：广告总开关（默认 `false`，首发不展示）。服务层/重试/看门狗/4 个 placement/埋点全部保留；`dailyPool()` 会摘掉「看完 1 次激励视频」、`achievements()` 会摘掉「广告鉴赏家」（与界面同源，不会半开半关）。开通流量主后填 `AD_UNIT_ID` + 改这一行 + 重新提审即可，不用动其它代码
- `STORY` / `storyFor` / `shouldShowStory` / `BOSS_LINES`：关卡开场剧情（第 1~8 关 + 第 9 关收尾；第 10 关起无；`meta.storySeen` 记录已看过）与三个 Boss 的登场台词

调试钩子（开发者工具控制台）：`databus.debug.addCoins(100)` / `addExp(200)` / `setTimeLeft(5)` / `giveWeapon('keyboard', 3)` / `killAll()` / `resetSave()`。

## 技术结构

```
game.js                 入口
js/render.js            375×667 设计分辨率适配 + 触摸坐标换算
js/core/config.js       全部数值配置（数据驱动）
js/core/save.js         存档结构版本(saveVer=2) / v1→v2 迁移 / 逐字段兜底（纯函数，可测）
js/core/databus.js      全局状态：存档(meta) + 局内(battle) + debug 钩子
js/core/pool.js         对象池（敌人/弹丸/特效复用，防掉帧）
js/core/audio.js        音效（bgm/爆炸，可开关）
js/entities/            敌人（含 Boss 召唤/狂暴）、弹丸（咖啡豆/键帽波/Bug 炸弹）、特效
js/systems/             武器行为、技能抽取与词缀、波次控制、工位伤害结算（减伤/护盾统一入口）、每日任务与免费宝箱、成就与图鉴统计
js/ui/                  战斗场景（含剧情卡）、合成棋盘、三选一、结算、首页、工位升级
js/services/            激励视频（含失败重试与占用看门狗；首发 ADS_ENABLED=false 不显示入口）、分享（主动+右上角转发、5:4 卡片图）、好友榜、埋点、错误监控
test/harness.js         无头运行环境桩（wx/canvas/计时/随机数/激励视频/存储/前后台），冒烟测试与模拟器共用
test/harness.spec.js    桩忠实度自检（54 项：广告订阅语义、存储 JSON 往返、切后台不出帧；只测桩不加载游戏）
test/smoke.js           Node 无头冒烟测试（393 项）
tools/sim.js            无头对局模拟器（三档机器人 + 指标表，改动前后对比用）
legacy/                 原打飞机示例代码（已排除打包，仅留档）
```

关键设计决策：**棋盘即防线**——武器从棋盘格自动朝战场开火，无需角色移动，操作只剩拖拽合成与技能选择（计划书 §4.1 的"工位"方案）。
